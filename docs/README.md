# Documentation

- **technical-design-document.docx** — full architecture, design decisions, and open
  questions for the Decap CMS integration, including the flow diagram in
  `diagrams/flow.png`.
- **pizza-manager-guide.pdf** — a 1–2 page illustrated guide for the Slow Dough owner/manager
  on how to use `/admin` day-to-day.
- **INTEGRATION-GUIDE.md** — step-by-step runbook for wiring GitHub Pages, the GitHub OAuth
  App and the Azure Functions OAuth proxy together (secrets, app settings, workflows,
  troubleshooting).
- **screenshots/** — source screenshots (captured with Playwright against a real running
  instance of the app) used in both documents. `screenshots/guide/` holds cropped/redacted
  versions used specifically in the manager PDF.
- **diagrams/flow.dot** — Graphviz source for the flow diagram (`flow.png`). Regenerate with:

  ```bash
  dot -Tpng flow.dot -o flow.png -Gdpi=150
  ```

## Regenerating the documents

Both documents are generated by small, reviewable Python scripts rather than hand-edited
binary files, so they can be regenerated any time the app, screenshots, or copy change:

```bash
pip install python-docx reportlab pillow
python3 build_tdd.py             # -> technical-design-document.docx
python3 build_manager_guide.py   # -> pizza-manager-guide.pdf
```

If you update the screenshots, replace the files under `screenshots/` (and
`screenshots/guide/` for the cropped manager-guide versions) with the same filenames, then
re-run the two scripts above.
